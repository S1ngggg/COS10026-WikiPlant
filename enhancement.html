This page highlights four major enhancements implemented in WikiPlant.

These enhancements improve the website’s responsiveness, usability, interactivity, and functionality beyond the basic project requirements.

Fluid Layout (Hamburger Menu)

The website uses a responsive fluid layout that adapts to different screen sizes. On smaller screens, the navigation links are replaced by a hamburger menu, allowing users to access the navigation without taking up excessive screen space.

Fixed Navigation Bar

The fixed navigation bar keeps the main navigation visible and accessible while users scroll through the website. This allows users to quickly access other pages without having to scroll back to the top of the page.

Flip Card

Flip cards provide an interactive way to display information. When users hover over a card, it flips to reveal additional details about a plant, such as its description or characteristics.

Google Map

A Google Map can be used to display geographical locations related to plant observations. This provides geographical context and helps users understand where particular plant records or observations are located.
