WikiPlant Website Enhancements

This page highlights four major enhancements implemented in WikiPlant. These enhancements improve the website's responsiveness, usability, interactivity, and functionality beyond the basic project requirements.

1. Fluid Layout (Hamburger Menu)

WikiPlant uses a responsive fluid layout that adapts to different screen sizes. On smaller screens, the navigation links are replaced by a hamburger menu. This allows users to access the website navigation without taking up excessive screen space.

2. Fixed Navigation Bar

The fixed navigation bar keeps the main navigation visible and accessible while users scroll through a page. This allows users to access other sections or pages without having to scroll back to the top.

3. Flip Card

Flip cards provide an interactive way to display information. When users hover over a card, it flips to reveal additional details about a plant, such as its description, characteristics, or other relevant information.

4. Google Map

Google Maps can display geographical locations related to plant observations. This provides geographical context and helps users understand where particular plant records or observations are located.
